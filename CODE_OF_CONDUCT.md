# Code of Conduct

## Our Pledge

We want gasm to be a welcoming learning space for people exploring assemblers, parsers, code generation, and systems programming.

Participants are expected to be respectful, patient, and constructive. This applies to issues, pull requests, code review, discussions, and any other project space.

## Expected Behavior

- Use welcoming and inclusive language.
- Give feedback that focuses on the code, docs, or idea.
- Be patient with beginners and people learning low-level programming.
- Accept constructive criticism gracefully.
- Prefer clear explanations over gatekeeping.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Dismissive comments about someone’s background, skill level, identity, or language ability.
- Publishing private information without permission.
- Repeated disruption of project discussions.

## Enforcement

Project maintainers may edit, hide, or remove comments and may block participation from people who violate this code of conduct.

If you see a problem, contact the maintainer privately with context and links when possible.

## Attribution

This code of conduct is intentionally short and project-sized. It is inspired by common open source community standards, including the Contributor Covenant.
